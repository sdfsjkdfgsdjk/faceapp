# Чужое лицо 🎭

Шуточное Android-приложение: в реальном времени накладывает лицо с фото на твоё лицо в камере.

## Возможности
- 🖼 — выбрать фото с лицом из галереи
- 👤 — «забрать» лицо того, кто сейчас в кадре (потом наведи камеру на другого человека)
- ⚪ — сделать фото, оно сохраняется в Галерею → Pictures/FaceSwapJoke
- 🔄 — фронтальная или основная камера
- 👁 — живая мимика: поверх чужого лица видны твои настоящие глаза и рот
- ✖ — убрать лицо

Работает без интернета. Распознавание лица — Google ML Kit (модель встроена в приложение).

## Как собрать
1. Установи [Android Studio](https://developer.android.com/studio) (любая свежая версия).
2. File → Open → выбери папку `FaceSwapJoke`. Дождись окончания Gradle Sync: при первом запуске скачиваются библиотеки, это занимает несколько минут.
3. Подключи телефон с включённой отладкой по USB (Настройки → О телефоне → 7 раз нажать на «Номер сборки» → Для разработчиков → Отладка по USB).
4. Нажми ▶ Run.

Нужен APK-файл, чтобы отправить другу? Build → Build App Bundle(s) / APK(s) → Build APK(s). Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

Требования: Android 10 и новее.

## Советы для лучшего результата
- Фото: лицо анфас, крупно, хорошо освещено, без очков и чёлки на глазах.
- В кадре лучше один человек: контуры лица ML Kit строит только для самого крупного лица.

## Как устроено
- `MainActivity.kt` — камера (CameraX), выбор фото, съёмка.
- `Faces.kt` — перевод контуров ML Kit в точки и подбор цвета кожи.
- `FaceMesh.kt` + `Delaunay.kt` — сетка из ~200 треугольников по 120 точкам лица.
- `FaceOverlayView.kt` — натягивание текстуры, растушёвка краёв, вырезы для глаз и рта.
